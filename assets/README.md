# Project artwork

`social-preview.svg` is the inspectable vector source for the repository social preview. It uses fixed text outlines and embeds the canonical Openly Useful reverse lockup and Open Monitor mark, including the source asset hashes in its metadata.

`social-preview.png` is the production 1280 × 640 GitHub upload. Keep it below GitHub's 1 MB limit and regenerate it whenever the vector source changes.
